# PrakWeb2

Proyek website sederhana berbasis HTML dan CSS.

Struktur file:

- `html/` : halaman web utama
- `css/` : file style
- `img/`, `icon/`, `video/` : aset gambar, ikon, dan video

Gunakan `html/index.html` sebagai halaman beranda. Semua file pendukung untuk tampilan website sudah tersedia di dalam repo ini.

Link Akses Website: https://prakweb2-five.vercel.app/
